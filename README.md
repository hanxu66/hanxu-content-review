# 内容数据复盘 Skill

版本：0.1.0 独立用户版。把已有内容数据核清楚，分开可比较与不可比较的样本，再形成下一轮可验证的变化。原有自用方法先补足去重、口径、分母和订单关联，用户版使用你自己的目标与平台。

适合已有公众号、短视频等内容及真实数据，希望知道下一轮改什么的人。没有数据不编造表现；只有数据表时不评价未读的观点、开头或剪辑。不自动登录、采集、投流、制作新内容或发布。

## 材料与写法

必需：本次想解决的问题、平台原始数据及统计截止。可以交原表、截图或粘贴数据；说明是否投流、内容对象及实际观察窗口。目标尚未明确时可以先核对数据，缺失项保留未知。

可选：对应稿件/成片和版本、用户反馈、可唯一关联的订单资料、上轮实验。分析内容原因才需对应内容；订单关联缺ID时明确未匹配，不强行补齐。原始数据保留，不把归一化表当原始证据。

[输入说明](references/input-schema.md)解释每个复算字段。[完整合成CSV](examples/synthetic-metrics.csv)是练习数据，不代表真实账号表现；包括重复快照和付费样本，以便看到去重和分组。

## 安装与完整最小示例

取得完整 `hanxu-content-review` 文件夹后交给可读Skill的AI助手安装，保留配套文件。旧版先备份到技能发现目录外，不覆盖自己的原表、报告或其他Skill。让助手读回名称、版本和实际位置。

```text
用 $hanxu-content-review 处理包内合成CSV，练习数据核查与复盘。我想提高自然内容的有效观看，没有稿件和评论正文。先指出数据覆盖和分组，再算中位数及缺失，不能推断开头、作者观点或投流因果。给下一轮最小实验及需要补什么材料。
```

真实使用时换成自己的材料。也可以只说：“这两张后台截图里数字对不上，先帮我核清楚。”不必先填CSV。

需要程序复算时，在技能目录运行：

```sh
python3 scripts/analyze_content_metrics.py examples/synthetic-metrics.csv
```

默认5条只是分组报告工作阈值，不表示统计显著或效果已验证。按实际任务可用 `--min-comparable` 指定其他阈值。脚本报冲突时先回原始数据，不把失败后的部分输出当完整报告。

## 文件与输出

| 文件 | 用途 | 是否要改 |
|---|---|---|
| `SKILL.md` | 核对、分析、实验与回流方法 | 通常不用 |
| `scripts/analyze_content_metrics.py` | 可选描述性复算 | 通常不用 |
| `references/input-schema.md` | 字段、单位、缺失与异常说明 | 通常不用 |
| `examples/synthetic-metrics.csv` | 完整合成输入 | 复制到自己目录后换真实材料 |
| `agents/openai.yaml`、`README.md`、`VERSION`、`SKILL-MANIFEST.json` | 发现、说明、版本与文件校验 | 通常不用 |

输出可读复盘报告，必要时附可编辑标准表。关键数字能回到原证据；结论、反解释、未知与下一轮实验分开。建议仍是待应用，真实采用后才记已应用待验证，真实结果才能支持验证或反证。不因报告存在就声称形成闭环。

## 依赖、费用与限制

需要可读完整Skill的AI助手；可选脚本用Python 3.9以上标准库，不需平台账号、额外API密钥或联网。读取Excel、看成片等按所用助手实际能力处理，缺工具据实说明。模型与其他服务费用按自己的账号承担，材料由所选AI服务处理，脚本本身不上传。

脚本检查不代替内容审读、真人采用或传播效果。本版测试范围见 VALIDATION.md；没有跨平台因果或收益保证。反馈用版本、去敏数据片段、口径和具体问题，不提交账号凭据。

## 练习得到的实际结果

以下结果来自本轮明确合成材料，不是客户效果或外部用户认可。

包内合成CSV有7行，去除完全重复快照后6条：自然组5条、付费组1条分别描述。自然组播放100、200、300、400、500，中位数300。评论缺失保留未知，不能补0；没有稿件和留存图，报告没有把差异归因为开头或剪辑，下一步先补齐同窗口材料。
