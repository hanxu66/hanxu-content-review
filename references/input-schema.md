# 内容数据输入

支持先读平台原表/截图，再映射下面字段，不要求用户懂字段名。CSV只是可选复算接口，不是开始对话的前提。Excel表可先导出CSV；公式值与显示精度另核对。

必需列：`content_id,platform,window_hours,distribution,content_type,views`。

- `content_id`：平台内容唯一ID或用户为本次设定的唯一标识，不能仅凭同题或同日就视为同一条。
- `platform`：实际平台；阅读、播放各自映射指标含义，不能合并不同平台计数。
- `window_hours`：从真实发布至截止的观察小时，必须为正数。24和72小时分组，近似值不能冒充精确值。
- `distribution`：`organic`自然、`paid`付费、`mixed`混合、`unknown`未知。平台只有总数时不要自行拆分自然与付费。
- `content_type`：用户实际分类，例如口播、图文、访谈；分类相同时也不自动证明受众可比。
- `views`：映射后的原播放/阅读次数，非负整数；未知留空，真实零填0。平台如果是人数/UV，应另说明口径且不要与次数混合。

可选列：`likes,comments,shares,follows`为非负整数，空白表示未知；`completion_rate`为0到1的小数，百分号和百分制先按真实字段含义转换。点赞/播放等比率必须指明分母语义，不自动称转化率。

重复完全相同的快照自动去重，冲突快照报错，需要先选择有凭据的截止版本。原始数据不覆盖。脚本输出分组描述、中位数与指标覆盖，以及有真实分母的比率；不是平台规律或因果判断。

UTF-8 CSV可含BOM。中文/空格路径作为完整参数传入，不要求改名。脚本不写文件、不联网、不上传；需要保存结果时由用户的助手写入指定目录。
